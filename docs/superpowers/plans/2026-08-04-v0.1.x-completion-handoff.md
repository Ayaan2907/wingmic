## 3 · Operational runbook (verified this session; cross-check `AGENTS.md`)

```bash
bun install --frozen-lockfile
bun run typecheck && bun run lint && bun run test   # turbo — builds @wingmic/db + extractor first
```
Bare `vitest` fails on `@wingmic/db/schema` until workspace deps are built — always go through turbo. **After any pull that touches `package.json`, re-run install and clear `apps/app/.next` before trusting typecheck** — stale installs reproduce phantom `react-force-graph-2d` / typed-route errors (burned this session).

Local app, zero secrets: `TURSO_DB_URL="file:$PWD/dev.db"` + random `BETTER_AUTH_SECRET` → `bun run db:apply` → `bun run dev:app` (port 3211). Magic link: `POST /api/auth/sign-in/magic-link` `{"email":"ada@example.com","callbackURL":"/chat"}` — link prints to the dev console when `RESEND_API_KEY` is unset. Note the `AGENTS.md` gotcha: `db:apply` runs in `packages/db`, so the app's own db needs the explicit `TURSO_DB_URL` path.

Playwright: pre-installed Chromium is build 1194 vs playwright-core 1.59.1's expected 1217 — pass `executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome'`; fake mic via `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream` + `grantPermissions(['microphone'])`; the orb pulses forever, so `click({ force: true })`.

4. PR to `staging`, fill the repo PR template, link the issue (`closes #N` / `part of #56`).
5. Update the tracking issue checklist; plan the next item only when the current one lands.
