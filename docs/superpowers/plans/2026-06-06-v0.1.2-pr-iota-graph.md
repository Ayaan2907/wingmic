# PR ι-graph — Graph screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add `/graph` — a force-directed canvas of the user's real entity graph (people, companies, events, topics), where tapping a node opens a floating card that links to that entity's detail page.

**Architecture:** New `graph.get` tRPC procedure (userId-scoped, mirrors `entity.detail`'s loading pattern over `entityCompanies`/`entityEvents`/`entityTopics`) returns `{ nodes, links }`. `GraphClient` renders them via `react-force-graph-2d` (already in deps), **dynamically imported with `ssr: false`** (it touches `window`/canvas). The page mounts inside the existing AppShell (PR λ-shell) — no per-screen nav. Data is **real-thin** (eng-review decision D=B): real query, no mock.

**Tech Stack:** Next.js 15 App Router, tRPC v11, Drizzle + libSQL, `react-force-graph-2d ^1.29.1`, Vitest. Branch: `feat/v0.1.2-pr-iota-graph` (stacked on `feat/v0.1.2-pr-lambda-shell`).

## Task 1: `graph.get` tRPC procedure + test

**Files:**
- Create: `apps/app/lib/trpc/routers/graph.ts`
- Create: `apps/app/lib/trpc/routers/graph.test.ts`
- Modify: `apps/app/lib/trpc/routers/_app.ts`

**Contract:**
```ts
// graph.get → scoped to ctx.user.id
{
  nodes: Array<{ id: string; kind: 'person' | 'company' | 'event' | 'topic'; label: string }>;
  links: Array<{ source: string; target: string; rel: 'works_at' | 'attended' | 'discussed' }>;
}
```
- `person` nodes = `entities` where `ownerUserId = userId AND deletedAt IS NULL`.
- For those entity ids, load `entityCompanies` / `entityEvents` / `entityTopics` with `sourceDeleted = false`.
- `company`/`event`/`topic` nodes = the canonical rows referenced by those edges (dedup by id).
- links: person→company (`works_at`), person→event (`attended`), person→topic (`discussed`). `source` = entityId, `target` = company/event/topic id.
- Mirror the exact filtering already proven in `entity.ts` (`isNull(deletedAt)`, `eq(sourceDeleted, false)`, `eq(ownerUserId, userId)`).

## Task 2: GraphClient (canvas + filter chips + selected-node card)

**Files:**
- Create: `apps/app/app/graph/GraphClient.tsx`
- Create: `apps/app/app/graph/__tests__/GraphClient.test.tsx`

Design reference: `design/v2/proto-screens-b.jsx ScreenGraph` + design.md §14.3 (desktop gains a detail pane; mobile raises a floating card above the nav). Node colors by kind: person=`#FFC452`, company=`#7DD3FC`, event=`var(--text-55)`/grey, topic=`#A78BFA` (the entity palette from `chat/_components/tokens.ts`).

**Critical:** `react-force-graph-2d` must be imported with `next/dynamic` + `ssr: false` — it references `window`. Importing it statically breaks SSR/build.

```tsx
import dynamic from 'next/dynamic';
const ForceGraph2D = dynamic(() => import('react-force-graph-2d'), { ssr: false });
```

Interaction (design.md §14.3 + §13.3): tap a node → set `selected` → render a floating card (14px radius, above the nav on mobile; a side detail pane on desktop is fine as a later polish, not required for this PR) showing the node label + kind + a link `→ open` to `/{kind}/{id}` (plain `<a>`, matching the repo's dynamic-href convention). Filter chips (people/orgs/events/topics) toggle which node kinds render. Empty state when `nodes.length === 0`: "no connections yet. hold the mic to capture someone."

- [ ] **Step 1: Write the failing GraphClient test**

Create `apps/app/app/graph/__tests__/GraphClient.test.tsx`. **Mock `react-force-graph-2d`** so jsdom doesn't touch canvas:

```tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { describe, it, expect, vi } from 'vitest';

// Mock the dynamic force-graph: render a button per node that fires onNodeClick.
vi.mock('next/dynamic', () => ({
  default: () => function MockGraph(props: any) {
    return (
      <div data-testid="force-graph">
        {props.graphData.nodes.map((n: any) => (
          <button key={n.id} onClick={() => props.onNodeClick?.(n)}>{n.label}</button>
        ))}
      </div>
    );
  },
}));

import { GraphClient } from '../GraphClient';

const DATA = {
  nodes: [
    { id: 'p1', kind: 'person', label: 'Ada' },
    { id: 'c1', kind: 'company', label: 'Acme' },
  ],
  links: [{ source: 'p1', target: 'c1', rel: 'works_at' }],
};

describe('GraphClient', () => {
  it('renders a node per graph node', () => {
    render(<GraphClient data={DATA} />);
    expect(screen.getByText('Ada')).toBeTruthy();
    expect(screen.getByText('Acme')).toBeTruthy();
  });

  it('tapping a node shows a card linking to its entity page', () => {
    render(<GraphClient data={DATA} />);
    fireEvent.click(screen.getByText('Ada'));
    const open = screen.getByRole('link', { name: /open/i });
    expect(open.getAttribute('href')).toBe('/person/p1');
  });

  it('shows an empty state with no nodes', () => {
    render(<GraphClient data={{ nodes: [], links: [] }} />);
    expect(screen.getByText(/no connections yet/i)).toBeTruthy();
  });
});
```
