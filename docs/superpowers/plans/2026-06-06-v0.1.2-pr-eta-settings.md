# PR η-settings — Settings screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps.

**Goal:** Add `/settings` — account / audio-retention / privacy / capture / advanced / about — that **really persists** the prefs that already have `users.*` columns (eng-review decision D=B: real-thin, not mock toggles).

**Architecture:** New `settings` tRPC router: `get` (read the caller's prefs) + `update` (partial write, **userId-scoped, enum Zod-validated**). `SettingsClient` renders the sections and fires `settings.update` on change. The columns exist from the α-0 migration — no new migration. Mounts inside AppShell.

**Tech Stack:** Next.js 15, tRPC v11, Drizzle + libSQL, Vitest. Branch: `feat/v0.1.2-pr-eta-settings` (stacked on `feat/v0.1.2-pr-zeta-acts`).

**Backing columns (`packages/db/src/schema.ts` `users`):** `audioRetentionMode` (enum `'24h'|'7d'|'forever'|'never'`, default `'24h'`), `linkerModelOverride` (nullable text), `preferredMicDeviceId` (nullable text), `asrLanguage` (text, default `'en-US'`), `acknowledgedPrivacy` (bool — managed by onboarding κ, shown read-only here).

## Task 1: settings tRPC (get + update) — userId-scoped, validated

**Files:**
- Create: `apps/app/lib/trpc/routers/settings.ts`
- Create: `apps/app/lib/trpc/routers/settings.test.ts`
- Modify: `apps/app/lib/trpc/routers/_app.ts`

**Contract:**
```ts
settings.get  → { audioRetentionMode: '24h'|'7d'|'forever'|'never';
                  linkerModelOverride: string | null;
                  preferredMicDeviceId: string | null;
                  asrLanguage: string;
                  acknowledgedPrivacy: boolean }   // read the caller's user row
settings.update(input) → { ok: true }              // partial; writes WHERE id = ctx.user.id
  input = z.object({
    audioRetentionMode: z.enum(['24h','7d','forever','never']).optional(),
    linkerModelOverride: z.string().max(120).nullable().optional(),
    preferredMicDeviceId: z.string().max(200).nullable().optional(),
    asrLanguage: z.string().min(2).max(20).optional(),
  })
```
Both `protectedProcedure`. `update` builds a patch object from only the provided keys and runs `ctx.db.update(users).set(patch).where(eq(users.id, ctx.user.id))`. **Never accept a userId from input** — always `ctx.user.id`.

- [ ] **Step 1: Write the failing router test**

Create `apps/app/lib/trpc/routers/settings.test.ts`, following the in-memory libSQL harness in `entity.test.ts`/`recall.test.ts` (createCaller with a ctx whose `user.id` is the seeded user). Assert:
- `update({ audioRetentionMode: '7d' })` then `get()` returns `audioRetentionMode: '7d'` for that user;
- a second user's row is unchanged after the first user's update (**isolation**);
- `update({ audioRetentionMode: 'bogus' })` throws a validation error (Zod enum) — assert it rejects;
- `get()` returns defaults for a freshly-seeded user (`'24h'`, `'en-US'`, `acknowledgedPrivacy:false`).

Use `drizzle-orm` `eq` and `* as schema from '@wingmic/db/schema'`.
